SpanIO is a C++17 cross-platform network framework based on header files: it abstracts a unified asynchronous IO interface on top of Linux and Windows, automatically selecting the most optimal IO model for the platform (epoll / io_uring / IOCP) at the bottom layer, integrating the programming semantics of Proactor and Reactor on the upper layer, allowing developers to write network services for both platforms with a single set of code and a single thinking model.
